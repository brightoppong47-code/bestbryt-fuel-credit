# BESTBRYT Fuel Credit

Fuel credit management app with driver registration, transactions, repayments, risk management and reporting.

The Reports page includes date and branch filters, separate principal, interest and penalty collection totals, and filtered PDF/CSV exports.

See [REPORT-UPDATE-README.md](REPORT-UPDATE-README.md) for update notes and installation instructions. This repository contains source code; it is not a live deployment. Existing Convex and Hercules configuration is required.
